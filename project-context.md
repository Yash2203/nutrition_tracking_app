# Project context

## Goal
A personal nutrition tracker similar to Cronometer for Yash's iPhone 16. It covers calories, food logging, daily weight, goals, barcode scanning, and AI food photo recognition with macros and micronutrients. It should include the best premium features from competitors and fix their common complaints.

## Constraints
- $0 cost to run for now.
- Shareable with friends, so it needs multi-user accounts.
- Built so it can be deployed and monetized later, including an App Store path.
- Completely separate from the marina_app repo. Code goes in a new private GitHub repo that Yash creates.
- Yash wants to confirm once where and how the repo is created.
